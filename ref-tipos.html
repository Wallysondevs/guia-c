C Tipos e Limites

Esta é a página de consulta rápida dos tipos do C: quantos bytes cada um ocupa, o menor e o maior valor que cabe nele, o tipo de cada número escrito no código e o que acontece quando um valor não cabe. O C não fixa quase nenhum tamanho: ele muda de máquina para máquina. Por isso, cada tabela mostra os valores medidos em duas máquinas diferentes, o gcc da Ana e o editor do guia. Para aprender com calma, veja as aulas Tipos de Dados, Inteiros, float e double, sizeof e stdint.h.

Tamanhos: sizeof e alignof

sizeof(T) dá o tamanho do tipo em bytes; alignof(T) C23 (no C11, _Alignof) dá o alinhamento: o endereço de uma variável desse tipo é sempre múltiplo desse número. Medidos com este programa:

#include <stdio.h>
#include <stddef.h>
#include <stdint.h>
#include <wchar.h>
#include <uchar.h>

#define MOSTRA(T) printf("%-20s %2zu %2zu\n", #T, sizeof(T), alignof(T))

int main(void) {
    printf("%-20s %2s %2s\n", "tipo", "sz", "al");
    MOSTRA(char);
    MOSTRA(bool);
    MOSTRA(short);
    MOSTRA(int);
    MOSTRA(long);
    MOSTRA(long long);
    MOSTRA(float);
    MOSTRA(double);
    MOSTRA(long double);
    MOSTRA(void *);
    MOSTRA(int (*)(void));
    MOSTRA(size_t);
    MOSTRA(ptrdiff_t);
    MOSTRA(intptr_t);
    MOSTRA(intmax_t);
    MOSTRA(max_align_t);
    MOSTRA(wchar_t);
    MOSTRA(char8_t);
    MOSTRA(char16_t);
    MOSTRA(char32_t);
    MOSTRA(nullptr_t);
    MOSTRA(_BitInt(7));
    MOSTRA(_BitInt(100));
    MOSTRA(int_least8_t);
    MOSTRA(int_fast8_t);
    MOSTRA(int_fast16_t);
    MOSTRA(int_fast32_t);
    MOSTRA(int_fast64_t);
    printf("char tem sinal? %s\n", (char)-1 < 0 ? "sim" : "não");
    printf("wchar_t tem sinal? %s\n", (wchar_t)-1 < 0 ? "sim" : "não");
    return 0;
}

  • char com ou sem sinal: nos dois, char sozinho tem sinal (vai de −128 a 127). Em processadores ARM (celulares, Raspberry Pi), ele costuma não ter (0 a 255). Para bytes, use unsigned char ou uint8_t.
  • Os unsigned (unsigned short, unsigned int…) têm o mesmo tamanho do tipo com sinal.
  • Só long, ponteiros e os tipos ligados a eles (size_t, ptrdiff_t, intptr_t, nullptr_t) mudam entre as duas máquinas. Se você precisa de um tamanho exato, use os tipos do stdint.h.

Os tipos com sinal vão de −2N−1 a 2N−1 − 1, e os sem sinal, de 0 a 2N − 1, onde N é o número de bits. Por isso o mínimo tem "um a mais" que o máximo: INT_MIN = −2147483648, INT_MAX = 2147483647.

stdint.h: inteiros de tamanho fixo

Quando o tamanho importa (um arquivo binário, um protocolo de rede, um valor que passa de 2 bilhões), use os tipos do <stdint.h> C99: eles têm o mesmo tamanho em toda máquina. Aula: stdint.h.

#include <stdio.h>
#include <stddef.h>
#include <stdint.h>
#include <inttypes.h>

int main(void) {
    printf("INT8_MIN   = %" PRId8 ", INT8_MAX = %" PRId8 ", UINT8_MAX = %" PRIu8 "\n", INT8_MIN, INT8_MAX, UINT8_MAX);
    printf("INT16_MIN  = %" PRId16 ", INT16_MAX = %" PRId16 ", UINT16_MAX = %" PRIu16 "\n", INT16_MIN, INT16_MAX, UINT16_MAX);
    printf("INT32_MIN  = %" PRId32 ", INT32_MAX = %" PRId32 "\n", INT32_MIN, INT32_MAX);
    printf("UINT32_MAX = %" PRIu32 "\n", UINT32_MAX);
    printf("INT64_MIN  = %" PRId64 "\n", INT64_MIN);
    printf("INT64_MAX  = %" PRId64 "\n", INT64_MAX);
    printf("UINT64_MAX = %" PRIu64 "\n", UINT64_MAX);
    printf("INTMAX_MAX = %" PRIdMAX "\n", INTMAX_MAX);
    printf("SIZE_MAX   = %zu\n", (size_t)SIZE_MAX);
    printf("PTRDIFF_MAX = %td\n", (ptrdiff_t)PTRDIFF_MAX);
    printf("INTPTR_MAX = %" PRIdPTR "\n", (intptr_t)INTPTR_MAX);
    printf("PRId64 = \"%s\", PRIu64 = \"%s\", PRIdPTR = \"%s\"\n", PRId64, PRIu64, PRIdPTR);
    return 0;
}

  • Por que PRId64? Porque o int64_t é um long no gcc (PRId64 vira "ld") e um long long no editor (vira "lld"). Escrever %ld à mão funcionaria só numa das duas máquinas. Veja a tabela do printf.
  • Literais de tamanho fixo: INT64_C(5000000000) e UINT32_C(7) escrevem o número já com o tipo certo.
  • No editor, os casts (size_t)SIZE_MAX são necessários: lá, SIZE_MAX, PTRDIFF_MAX e INTPTR_MAX são unsigned int/int, e o Clang avisa format specifies type 'size_t' (aka 'unsigned long') but the argument has type 'unsigned int' num %zu sem o cast. No gcc, não faz diferença.

Na prática: um float guarda uns 6 a 7 algarismos; um double, 15 a 16. Para dinheiro, guarde centavos num inteiro (long long centavos). Para comparar dois double, use uma tolerância: fabs(a - b) < 1e-9. Aula: float e double.

O tipo de cada literal

Todo número escrito no código (um literal) tem um tipo. Medido com _Generic (aula _Generic), que escolhe um texto conforme o tipo:

#include <stdio.h>
#include <limits.h>
#include <stddef.h>

#define TIPO(x) _Generic((x), \
    char: "char", int: "int", unsigned: "unsigned int", \
    long: "long", unsigned long: "unsigned long", \
    long long: "long long", unsigned long long: "unsigned long long", \
    float: "float", double: "double", long double: "long double", \
    bool: "bool", nullptr_t: "nullptr_t", default: "outro")

int main(void) {
    printf("42          -> %s\n", TIPO(42));
    printf("42u         -> %s\n", TIPO(42u));
    printf("42L         -> %s\n", TIPO(42L));
    printf("42LL        -> %s\n", TIPO(42LL));
    printf("42ull       -> %s\n", TIPO(42ull));
    printf("2147483648  -> %s\n", TIPO(2147483648));
    printf("0xFFFFFFFF  -> %s\n", TIPO(0xFFFFFFFF));
    printf("3.14        -> %s\n", TIPO(3.14));
    printf("3.14f       -> %s\n", TIPO(3.14f));
    printf("3.14L       -> %s\n", TIPO(3.14L));
    printf("'A'         -> %s\n", TIPO('A'));
    printf("true        -> %s\n", TIPO(true));
    printf("nullptr     -> %s\n", TIPO(nullptr));
    printf("1'000'000   -> %d\n", 1'000'000);
    printf("0b1010      -> %d\n", 0b1010);
    printf("sizeof(3wb) = %zu, sizeof(200uwb) = %zu\n", sizeof(3wb), sizeof(200uwb));
    char c = 'A';
    printf("c + 1       -> %s\n", TIPO(c + 1));
    printf("1u + -2     -> %s = %u\n", TIPO(1u + -2), 1u + -2);
    printf("-1 < 1u     -> %d\n", -1 < 1u);
    printf("(unsigned char)300 = %d, (signed char)200 = %d\n", (unsigned char)300, (signed char)200);
    printf("UINT_MAX + 1u = %u\n", UINT_MAX + 1u);
    printf("(int)3.99 = %d, (int)-3.99 = %d\n", (int)3.99, (int)-3.99);
    float f = 16777217;
    printf("float 16777217 -> %.1f\n", f);
    printf("0.1f == 0.1 -> %d\n", 0.1f == 0.1);
    return 0;
}

A soma das vendas ficou negativa

Com int janeiro = 1500000000, fevereiro = 1500000000;, a conta janeiro + fevereiro dá -1294967296, sem aviso nenhum (os valores só são conhecidos na execução). Guardar o resultado num long long não basta: a conta é feita em int e estoura antes. Converta um dos lados antes da conta: (long long)janeiro + fevereiro. É a missão abaixo.

Experimente

Experimente: veja os tamanhos no editor (WebAssembly de 32 bits) e compare com a tabela do gcc. Acrescente outros tipos: unsigned short, int16_t, uma struct sua…

#include <stdio.h>
#include <stdint.h>
#include <limits.h>

struct produto {
    char codigo;
    int quantidade;
    double preco;
};

int main(void) {
    printf("int: %zu bytes, long: %zu, long long: %zu\n", sizeof(int), sizeof(long), sizeof(long long));
    printf("ponteiro: %zu bytes, size_t: %zu\n", sizeof(void *), sizeof(size_t));
    printf("int64_t: %zu bytes\n", sizeof(int64_t));
    printf("struct produto: %zu bytes (1 + 4 + 8 = 13 sem os buracos)\n", sizeof(struct produto));
    printf("INT_MAX = %d, LONG_MAX = %ld\n", INT_MAX, LONG_MAX);
    return 0;
}

Missão: a lojinha da Ana vendeu R$ 1,5 bilhão em janeiro e outro tanto em fevereiro (é uma lojinha otimista), mas o total sai negativo. Guarde o total num long long, faça a conta nesse tipo e mostre com %lld, para sair Total: 3000000000. (Não use long: no editor ele tem 4 bytes e estoura igual.)

#include <stdio.h>

int main(void) {
    int janeiro = 1500000000;
    int fevereiro = 1500000000;
    int total = janeiro + fevereiro;
    printf("Total: %d\n", total);
    return 0;
}

#include <stdio.h>

int main(void) {
    int janeiro = 1500000000;
    int fevereiro = 1500000000;
    long long total = (long long)janeiro + fevereiro;
    printf("Total: %lld\n", total);
    return 0;
}

Resumo

  • Iguais em quase toda máquina: char 1, short 2, int 4, long long 8, float 4, double 8 bytes.
  • Mudam: long, ponteiros e size_t (8 bytes no Linux de 64 bits, 4 no editor). Para tamanho exato, int32_t, int64_t… do stdint.h, com PRId64 no printf.
  • Limites: INT_MAX = 2147483647, LLONG_MAX = 9223372036854775807 (limits.h); DBL_EPSILON, DBL_DIG = 15 (float.h).
  • Sem sinal dá a volta; conta com sinal que estoura é comportamento indefinido. Converta antes da conta: (long long)a + b.
  • Cuidado com int × unsigned (-1 < 1u é falso) e com 'A', que é um int.
