Projeto Lista de Tarefas

A Ana anota o que precisa fazer na lojinha em papeizinhos colados na parede: comprar papel, pagar a luz, ligar para o fornecedor. Neste projeto, os papeizinhos viram uma lista ligada em C. Cada tarefa é criada com malloc quando a Ana a digita e destruída com free quando sai da lista, e a lista cresce e encolhe sem tamanho máximo. No fim, o valgrind confere que nenhum byte foi esquecido.

Você vai praticar
  • Montar uma lista ligada de structs com ->, inserindo no fim.
  • Reservar dois blocos por tarefa com malloc: o nó e o título, do tamanho exato (Strings Dinâmicas).
  • Achar a tarefa pelo número, removê-la (inclusive a primeira) e remover várias numa passada só.
  • Liberar tudo, na ordem certa, e ler os relatórios do valgrind.
  • Guardar a lista num arquivo de texto e montá-la de novo ao abrir.

O que vamos construir

O programa pronto, rodando dentro do valgrind na máquina da Ana. Ele carrega as tarefas salvas, a Ana conclui uma, acrescenta outra, remove uma terceira e limpa as feitas. No fim, o relatório: toda a memória foi devolvida.

Versão 1 · A tarefa, a lista e o primeiro valgrind

Imagine os papeizinhos da Ana presos por clipes, um atrás do outro: cada papel tem a tarefa e um clipe que segura o próximo. Para achar a terceira tarefa, você começa pelo primeiro papel e segue os clipes. Na lista ligada, o papel é uma struct, o clipe é um ponteiro (prox), e o último papel tem o clipe solto: NULL.

A diferença para a lista de números de Listas Ligadas é o texto. Um título pode ter 5 letras ou 200. Em vez de reservar um array de 200 bytes em toda tarefa, o nó guarda um ponteiro para um texto criado com malloc, do tamanho exato. Assim, cada tarefa ocupa dois blocos de memória, e os dois têm de ser liberados.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct Tarefa {
    char *titulo;           // texto do tamanho exato, criado com malloc
    bool feita;
    struct Tarefa *prox;    // a próxima tarefa (NULL na última)
} Tarefa;

// Cria uma tarefa nova, fora da lista. Encerra o programa se faltar memória.
Tarefa *nova_tarefa(const char *titulo) {
    Tarefa *t = malloc(sizeof *t);
    char *copia = malloc(strlen(titulo) + 1);
    if (t == NULL || copia == NULL) {
        fprintf(stderr, "Sem memória\n");
        exit(1);
    }
    strcpy(copia, titulo);
    t->titulo = copia;
    t->feita = false;
    t->prox = NULL;
    return t;
}

// Põe a tarefa no fim da lista e devolve o começo da lista.
Tarefa *adicionar(Tarefa *lista, Tarefa *t) {
    if (lista == NULL) {
        return t;
    }
    Tarefa *p = lista;
    while (p->prox != NULL) {
        p = p->prox;
    }
    p->prox = t;
    return lista;
}

void apagar(Tarefa *t) {
    free(t->titulo);        // primeiro o texto...
    free(t);                // ...depois a tarefa
}

void listar(const Tarefa *lista) {
    if (lista == NULL) {
        printf("Nenhuma tarefa. Aproveite o dia!\n");
        return;
    }
    int n = 0;
    int pendentes = 0;
    for (const Tarefa *p = lista; p != NULL; p = p->prox) {
        n++;
        printf("%d. [%c] %s\n", n, p->feita ? 'x' : ' ', p->titulo);
        if (!p->feita) {
            pendentes++;
        }
    }
    printf("Pendentes: %d de %d\n", pendentes, n);
}

void liberar(Tarefa *lista) {
    while (lista != NULL) {
        Tarefa *prox = lista->prox;
        apagar(lista);
        lista = prox;
    }
}

int main(void) {
    Tarefa *lista = NULL;           // a lista começa vazia
    lista = adicionar(lista, nova_tarefa("Comprar papel A4"));
    lista = adicionar(lista, nova_tarefa("Pagar a conta de luz"));
    lista = adicionar(lista, nova_tarefa("Ligar para o fornecedor"));
    lista->prox->feita = true;      // a segunda já foi feita

    listar(lista);
    liberar(lista);
    return 0;
}

Versão 2 · O menu: adicionar e concluir

Agora a lista começa vazia e a Ana a monta pelo teclado. Para concluir uma tarefa, ela digita o número que aparece na listagem. Numa lista ligada não existe lista[2]: para chegar na tarefa 3, é preciso começar na primeira e seguir os clipes, contando. É o que faz a função achar. As funções de leitura são as mesmas da Calculadora e do Estoque.

As partes novas (as funções da versão 1 continuam iguais):

// Devolve a tarefa de número n (1, 2, 3...) ou NULL se ela não existe.
Tarefa *achar(Tarefa *lista, int n) {
    int i = 1;
    for (Tarefa *p = lista; p != NULL; p = p->prox) {
        if (i == n) {
            return p;
        }
        i++;
    }
    return NULL;
}

// Mostra a pergunta e lê uma linha, sem o Enter do fim.
// Devolve false se a entrada acabou (Ctrl+D).
bool ler_linha(const char *pergunta, char *linha, int tamanho) {
    printf("%s", pergunta);
    if (fgets(linha, tamanho, stdin) == NULL) {
        return false;
    }
    linha[strcspn(linha, "\n")] = '\0';
    return true;
}

// Lê um número de 1 a 100000. Devolve -1 se não for um número assim.
int ler_numero(const char *pergunta) {
    char linha[100];
    if (!ler_linha(pergunta, linha, sizeof linha)) {
        return -1;
    }
    char *fim = NULL;
    long n = strtol(linha, &fim, 10);
    if (fim == linha || *fim != '\0' || n < 1 || n > 100000) {
        return -1;
    }
    return (int)n;
}

Duas opções novas: 4) Remover tira uma tarefa pelo número, e 5) Limpar feitas tira todas as que já foram feitas, de uma vez. Remover de uma lista ligada é "soltar o clipe": a tarefa de antes passa a segurar a de depois, e a do meio fica livre para o free.

E se a tarefa removida for a primeira? Não existe "tarefa de antes" (ant é NULL): quem muda é o próprio começo da lista, que passa a ser a segunda tarefa. Por isso remover devolve o começo da lista, como adicionar.

Tarefa *remover(Tarefa *lista, int n) {

    Tarefa *p = lista;
    for (int i = 1; p != NULL && i < n; i++) {

        p = p->prox;

Desafios extras

  1. Editar o título. Uma opção que troca o texto de uma tarefa. Cuidado com a memória: libere o título antigo e reserve um novo, do tamanho certo. Confira com o valgrind.
  2. Mover para o topo. Uma opção que leva a tarefa n para o começo da lista, sem criar nem apagar nós: só trocando ponteiros.
  3. Desmarcar. Concluir uma tarefa já feita desfaz a marca (t->feita = !t->feita).
  4. Prioridade. Acrescente bool urgente e grave [!] no arquivo para as urgentes; liste as urgentes primeiro.
  5. Desfazer a última remoção. Em vez de apagar o nó removido, guarde-o numa variável lixeira e ofereça "desfazer"; apague-o de verdade só quando outra remoção acontecer ou no fim do programa.

Resumo

  • Cada tarefa é um nó criado com malloc, ligado ao próximo por prox; a última aponta para NULL.
  • Um título de tamanho exato é um segundo bloco: malloc(strlen(t) + 1). Dois malloc, dois free: primeiro o título, depois o nó.
  • Para achar a tarefa n, percorra contando; numa lista ligada não existe lista[n].
  • Remover é ligar a anterior à seguinte; a primeira tarefa é um caso à parte, porque muda o começo da lista.
  • Num laço que apaga, guarde o prox antes do free.
  • Ponteiros não vão para arquivo: salve o conteúdo (aqui, em texto) e monte a lista de novo ao abrir.
  • O programa "funcionar" não prova nada sobre a memória: rode o valgrind --leak-check=full e procure All heap blocks were freed e 0 errors.
