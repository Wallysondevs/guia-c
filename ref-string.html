C string.h

Esta é a página de consulta rápida do <string.h>, a biblioteca de funções para texto (as str…) e para blocos de memória (as mem…). Aqui estão todas, em tabelas: o que cada uma faz, o que devolve, um exemplo com a saída real e a aula onde ela é explicada. Para aprender com calma, veja as aulas Strings, Funções de String e Ponteiros e Strings.

Todas as saídas foram produzidas de verdade: no gcc 15.2 da máquina da Ana (Linux de 64 bits, pasta ~/c/ref, comando gcc -std=c23 -Wall -Wextra) e no editor do guia (Clang em WebAssembly). Quando os dois diferem, a tabela diz.

Antes de tudo: três regras

Uma string é um array de char que termina em '\0'
Toda função str… anda pelo texto até achar o '\0' (o caractere de código zero). Sem ele, a função continua lendo a memória que vem depois. Aula: Strings.
Nenhuma função sabe o tamanho do seu array
Elas recebem só um ponteiro para o primeiro caractere (aula Ponteiros e Strings). Quem garante que cabe é você. Um strcpy que não cabe escreve além do fim do array, sem erro nenhum na hora.
size_t
É o tipo dos tamanhos (um inteiro sem sinal). Mostre com %zu: printf("%zu", strlen(nome)). Aula: sizeof.

Nas tabelas, d é o destino (onde a função escreve), o é a origem (de onde ela lê), s é uma string e n é um número de bytes.

Tamanho, cópia e junção

#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int main(void) {
    char nome[20] = "Ana";
    printf("strlen=%zu sizeof=%zu\n", strlen(nome), sizeof nome);
    char copia[20];
    strcpy(copia, nome);
    printf("strcpy:  [%s]\n", copia);
    strcat(copia, " Souza");
    printf("strcat:  [%s]\n", copia);
    char curto[5];
    strncpy(curto, "Banana", sizeof curto - 1);
    curto[sizeof curto - 1] = '\0';
    printf("strncpy: [%s]\n", curto);
    char frase[20] = "Oi";
    strncat(frase, ", Ana Souza", 5);
    printf("strncat: [%s]\n", frase);
    char *dup = strdup("Caderno");
    char *pedaco = strndup("Caderno", 4);
    printf("strdup:  [%s] strndup: [%s]\n", dup, pedaco);
    free(dup);
    free(pedaco);
    char destino[20] = "";
    char *fim = memccpy(destino, "maçã;pera", ';', sizeof destino);
    printf("memccpy: [%.*s] copiou %td bytes\n", (int)(fim - destino), destino, fim - destino);
    return 0;
}

  • strlen × sizeof: strlen(nome) é o tamanho do texto (3); sizeof nome é o tamanho do array (20). Dentro de uma função que recebeu char *s, sizeof s é o tamanho do ponteiro (8 no gcc, 4 no editor), não do array. Aula: sizeof.
  • strlen conta bytes, não letras. Em UTF-8, cada letra acentuada ocupa 2 bytes. Aula: Acentos e UTF-8.
  • strdup e strndup existem há décadas no Linux (POSIX), mas só entraram no C padrão no C23.

Comparar

#include <stdio.h>
#include <string.h>

int main(void) {
    printf("strcmp(\"Ana\", \"Bia\") = %d\n", strcmp("Ana", "Bia"));
    printf("strcmp(\"Bia\", \"Ana\") = %d\n", strcmp("Bia", "Ana"));
    printf("strcmp(\"Ana\", \"Ana\") = %d\n", strcmp("Ana", "Ana"));
    printf("strcmp(\"ana\", \"Ana\") = %d\n", strcmp("ana", "Ana"));
    printf("strcmp(\"Ana\", \"Ana Souza\") = %d\n", strcmp("Ana", "Ana Souza"));
    printf("strncmp(\"Banana\", \"Bando\", 3) = %d\n", strncmp("Banana", "Bando", 3));
    printf("strncmp(\"Banana\", \"Bando\", 4) = %d\n", strncmp("Banana", "Bando", 4));
    int a[3] = {1, 2, 3}, b[3] = {1, 2, 4};
    printf("memcmp(a, b, sizeof a) = %d\n", memcmp(a, b, sizeof a));
    printf("strcoll(\"abacate\", \"Banana\") = %d\n", strcoll("abacate", "Banana"));
    return 0;
}

Teste o sinal, nunca o número

O C só garante o sinal do resultado. O número em si muda de biblioteca para biblioteca: strncmp("Banana", "Bando", 4) deu -3 no gcc ('a' − 'd') e -1 no editor. Escreva if (strcmp(a, b) < 0), nunca if (strcmp(a, b) == -1). E, para saber se são iguais, strcmp(a, b) == 0; o == entre duas strings compara endereços (veja Erros comuns).

Procurar e dividir

#include <stdio.h>
#include <string.h>

int main(void) {
    const char *email = "ana.souza@exemplo.com";
    const char *arroba = strchr(email, '@');
    printf("strchr:  [%s] posição %td\n", arroba, arroba - email);
    printf("strrchr: [%s]\n", strrchr(email, '.'));
    printf("strstr:  [%s]\n", strstr(email, "souza"));
    printf("strchr não achou: %s\n", strchr(email, '#') == NULL ? "NULL" : "achou");
    printf("strpbrk: [%s]\n", strpbrk("R$ 12,90", "0123456789"));
    printf("strspn:  %zu\n", strspn("2026-10-17", "0123456789"));
    printf("strcspn: %zu\n", strcspn("Ana\n", "\n"));
    char linha[] = "Ana\n";
    linha[strcspn(linha, "\n")] = '\0';
    printf("sem Enter: [%s]\n", linha);
    char *p = memchr("abc\0def", 'e', 7);
    printf("memchr:  [%s]\n", p);
    char lista[] = "arroz,feijão,,café";
    for (char *item = strtok(lista, ","); item != NULL; item = strtok(NULL, ",")) {
        printf("strtok:  [%s]\n", item);
    }
    printf("depois do strtok: [%s]\n", lista);
    return 0;
}

  • Sempre teste o NULL antes de usar o resultado de strchr, strstr etc.: printf("%s", strchr(email, '#')) com um resultado NULL é comportamento indefinido. Aula: Ponteiro Nulo.
  • strtok não funciona numa string literal (char *lista = "a,b"), porque escreve nela; use um array (char lista[] = "a,b"). Ela também guarda a posição numa variável escondida: não dá para usar strtok em duas strings ao mesmo tempo. A versão que resolve isso é a strtok_r, do POSIX: funciona direto no gcc e, no editor, com #define _DEFAULT_SOURCE antes dos #include.
Novidade do C23: strchr respeita o const

No C23, strchr, strrchr, strstr, strpbrk e memchr devolvem const char * quando recebem uma string const. Por isso, no programa acima, o resultado vai para const char *arroba. Com char *arroba = strchr(email, '@');, o gcc 15 avisa:

procurar.c:6:20: warning: initialization discards ‘const’ qualifier from pointer target type [-Wdiscarded-qualifiers]
    6 |     char *arroba = strchr(email, '@');
      |                    ^~~~~~

O Clang do editor ainda não avisa. Aula: const e Ponteiros.

Blocos de memória: as funções mem…

As mem… trabalham com bytes, não com texto: recebem um void * (qualquer endereço; aula void*) e um número de bytes, e não ligam para o '\0'. Servem para arrays de qualquer tipo e para structs.

#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void) {
    int notas[5];
    memset(notas, 0, sizeof notas);
    printf("memset 0: %d %d %d %d %d\n", notas[0], notas[1], notas[2], notas[3], notas[4]);
    memset(notas, 1, sizeof notas);
    printf("memset 1: %d\n", notas[0]);
    char senha[8] = "segredo";
    memset(senha, '*', strlen(senha));
    printf("memset '*': [%s]\n", senha);
    int origem[3] = {7, 8, 9}, copia[3];
    memcpy(copia, origem, sizeof origem);
    printf("memcpy: %d %d %d\n", copia[0], copia[1], copia[2]);
    char texto[20] = "abcdef";
    memmove(texto + 2, texto, 4);
    printf("memmove: [%s]\n", texto);
    memset_explicit(senha, 0, sizeof senha);
    printf("memset_explicit: strlen=%zu\n", strlen(senha));
    printf("strerror(ENOENT): %s\n", strerror(ENOENT));
    printf("strerror(EACCES): %s\n", strerror(EACCES));
    printf("strerror(0): %s\n", strerror(0));
    return 0;
}

Por que memset_explicit? Com otimização (-O2), o compilador pode apagar um memset(senha, 0, …) feito logo antes de a variável deixar de existir, já que "ninguém mais vai ler". A senha fica na memória. O memset_explicit não pode ser apagado.

Erros comuns

Este programa junta os enganos mais frequentes com strings. O -Wall pega todos, mas o programa compila e roda:

#include <stdio.h>
#include <string.h>

void limpar(char *s) {
    memset(s, 0, sizeof s);
}

int main(void) {
    char nome[4];
    strcpy(nome, "Ana Souza");
    char a[] = "Ana", b[] = "Ana";
    if (a == b) printf("iguais\n");
    const char *c = "Ana";
    if (c == "Ana") printf("igual ao literal\n");
    char sigla[3];
    strncpy(sigla, "SPX", sizeof sigla);
    limpar(nome);
    printf("%s %s\n", nome, sigla);
    return 0;
}

O que significa: "ana" é uma string literal, e o gcc a guarda numa parte da memória que só pode ser lida. O char *nome só aponta para ela; escrever ali derruba o programa. Nenhum aviso, nem com -Wall. No editor, o programa mostra Depois: Ana sem erro, mas continua errado.

Como consertar: para um texto que muda, use um array, que é uma cópia sua: char nome[] = "ana";. Para um texto que não muda, deixe claro com const char *nome = "ana";: aí o compilador dá erro se você tentar escrever. Aula: Ponteiros e Strings.

O strcat num array sem valor inicial

char frase[50]; strcat(frase, "Oi"); procura o '\0' do fim de frase, mas o array tem lixo: o texto vai parar num lugar qualquer. Como consertar: comece com uma string vazia, char frase[50] = "";. Aula: Strings.

O fgets deixou o Enter

Depois de fgets(nome, sizeof nome, stdin), o nome termina em '\n': um strcmp(nome, "Ana") dá diferente e um printf("[%s]", nome) pula linha antes do ]. Como consertar: nome[strcspn(nome, "\n")] = '\0'; (é a missão abaixo). Aula: fgets.

Experimente

Missão: o programa lê o nome da Ana com fgets (a entrada já vem preenchida com Ana Souza), mas o ] sai na linha de baixo e o tamanho conta um byte a mais. Use strcspn para tirar o Enter, de modo que a saída seja Olá, [Ana Souza]! Seu nome tem 9 bytes. Depois, teste outras funções da página na mesma caixa.

#include <stdio.h>
#include <string.h>

int main(void) {
    char nome[40];
    printf("Seu nome: ");
    if (fgets(nome, sizeof nome, stdin) == NULL) {
        return 1;
    }
    // tire o '\n' aqui

    printf("Olá, [%s]! Seu nome tem %zu bytes.\n", nome, strlen(nome));
    return 0;
}

#include <stdio.h>
#include <string.h>

int main(void) {
    char nome[40];
    printf("Seu nome: ");
    if (fgets(nome, sizeof nome, stdin) == NULL) {
        return 1;
    }
    nome[strcspn(nome, "\n")] = '\0';

    printf("Olá, [%s]! Seu nome tem %zu bytes.\n", nome, strlen(nome));
    return 0;
}

Resumo

  • Tamanho: strlen (bytes até o '\0'; não é o sizeof do array).
  • Cópia e junção: strcpy, strcat (não conferem o tamanho), strncpy (pode deixar sem '\0'), strncat, strdup/strndup (memória nova, com free). Prefira snprintf.
  • Comparação: strcmp, strncmp, memcmp, strcoll. Teste == 0, < 0 ou > 0, nunca == -1. Nunca == entre strings.
  • Busca: strchr, strrchr, strstr, strpbrk, memchr (devolvem ponteiro ou NULL), strspn, strcspn (devolvem contagens). strtok divide, mas estraga a string e pula campos vazios.
  • Memória: memset (byte a byte), memcpy (sem sobreposição), memmove (com sobreposição), memset_explicit (para senhas, C23).
  • strerror(errno) dá o texto do erro do sistema.
