C Erros Comuns

Quando algo dá errado, o C fala inglês, em frases curtas e às vezes misteriosas. Esta página junta as mensagens que você mais vai ver, em três momentos: na compilação (o gcc), na ligação (o ld) e na execução (o seu programa caindo). Cada uma vem com o que ela quer dizer, como consertar e a aula onde o assunto é explicado. Todas foram provocadas de verdade.

Como usar esta página
  • Copie um pedaço da mensagem que apareceu para você (por exemplo, undeclared) e procure aqui com Ctrl+F.
  • Os programas ficam na pasta ~/c/erros da Ana e foram compilados com o comando padrão do guia: gcc -std=c23 -Wall -Wextra arquivo.c -o programa. No seu computador, o nome do arquivo e o número da linha serão outros; o texto da mensagem é o mesmo.
  • As mensagens do gcc saem em inglês, com aspas tipográficas ‘assim’. As do ligador e do terminal saem em português na máquina da Ana, porque esses programas têm tradução instalada; a versão em inglês aparece ao lado, porque é a que você vai achar nos fóruns.
  • O editor do guia usa o Clang, não o gcc: as mensagens dizem a mesma coisa com outras palavras. Por isso, cada tabela tem as duas colunas. Veja também O Editor do Guia.

"Não sei o que é": três jeitos de achar o erro
  1. Leia só a primeira mensagem error: e olhe a linha dela e a de cima.
  2. Copie o texto da mensagem (sem o nome do arquivo e os números) e procure nesta página ou na internet.
  3. Comente metade do código (/* … */) e compile de novo, até achar a linha culpada.

Avisos (warning)

Um aviso não impede o programa de ser criado, mas quase sempre aponta um bug. Compile sempre com -Wall -Wextra, e trate cada aviso como erro (a opção -Werror faz isso de verdade). Este programa junta os avisos mais comuns:

#include <stdio.h>

int maior(int a, int b) {
    if (a > b) {
        return a;
    }
}

int *criar(void) {
    int local = 7;
    return &local;
}

int main(int argc, char *argv[]) {
    int sobra;
    int x;
    printf("%d\n", x);
    x == 5;
    if (x > 5);
    {
        printf("maior\n");
    }
    int opcao = 1;
    switch (opcao) {
        case 1:
            printf("um\n");
        case 2:
            printf("dois\n");
            break;
    }
    if (x > 0)
        printf("a\n");
        printf("b\n");
    printf("%d %p\n", maior(1, 2), (void *)criar());
    return 0;
}

Códigos de saída

Todo programa termina com um número, que o terminal guarda em $? (echo $? mostra) e que o editor mostra como [código de saída: N]. Acima de 128, é 128 + o número do sinal que matou o programa. Aula: exit e atexit.

Resumo

  • Compilação (arquivo:linha:coluna: error:): conserte o primeiro erro primeiro e olhe também a linha de cima. Os mais comuns: undeclared, expected ‘;’, implicit declaration, aspas e chaves sem par.
  • Avisos (warning:): quase sempre são bugs. Compile com -Wall -Wextra e deixe zero avisos.
  • Ligação (referência não definida para, collect2: error: ld returned 1 exit status): falta uma função, o main, um .c no comando ou o -lm.
  • Execução: Falha de segmentação (139), Abortado (134: assert, double free, stack smashing), Exceção de ponto flutuante (136). Ache a linha com gdb ou -fsanitize=address.
  • No editor, as mensagens são do Clang, e muitos erros de memória passam calados: confira no gcc.
