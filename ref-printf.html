C printf e scanf

Esta é a página de consulta rápida do printf ("print formatted", imprimir formatado) e do scanf ("scan formatted", ler formatado). Aqui estão, em tabelas, todos os formatos, ajustes e armadilhas. Para aprender com calma, passo a passo, veja as aulas Saída com printf, Formatos do printf e Entrada com scanf.

Todas as saídas foram produzidas de verdade: no gcc 15.2 da máquina da Ana (Linux de 64 bits, pasta ~/c/ref, comando gcc -std=c23 -Wall -Wextra) e no editor do guia (Clang em WebAssembly). Quando os dois diferem, a tabela diz.

Anatomia de um formato

Cada lacuna do printf começa com % e termina com uma letra (o especificador). Entre os dois podem vir, nesta ordem, quatro ajustes opcionais:

%  [flags]  [largura]  [.precisão]  [tamanho]  especificador
%     -        10          .2           l            f        →  %-10.2lf
flags
Zero ou mais destes: - (alinhar à esquerda), + (sempre mostrar o sinal), espaço, # (forma alternativa), 0 (completar com zeros). Tabela.
largura
Número mínimo de caracteres que a lacuna ocupa. Se o valor é maior, ela cresce: a largura nunca corta. * = "a largura vem do próximo argumento".
.precisão
Um ponto seguido de um número. O sentido muda com o tipo: casas decimais no %f, algarismos significativos no %g, dígitos mínimos no %d, caracteres máximos no %s. .* = vem do próximo argumento.
tamanho
Diz o tamanho do valor: hh h l ll j z t L (e wN no C23). Tabela.
especificador
A letra que diz o tipo e a forma de mostrar: d, f, s… Tabela.

Especificadores do printf

Medidos com este programa (os colchetes mostram onde cada lacuna começa e termina):

#include <stdio.h>

int main(void) {
    int n = 255;
    double x = 3.14159;
    printf("[%d] [%i] [%u]\n", -42, -42, 42u);
    printf("[%o] [%x] [%X] [%#o] [%#x] [%#X]\n", n, n, n, n, n, n);
    printf("[%f] [%F] [%e] [%E]\n", x, x, x, x);
    printf("[%g] [%G] [%g] [%g]\n", x, 0.00001234, 1e20, 100000.0);
    printf("[%a] [%A]\n", 1.0, 0.5);
    printf("[%c] [%s] [%%]\n", 'A', "Ana");
    printf("[%b] [%#b] [%B]\n", 10u, 10u, 5u);
    return 0;
}

  • %d e %i são iguais no printf. No scanf não: %i entende 0x1F como hexadecimal e 017 como octal (veja a tabela do scanf).
  • %g troca para a notação científica quando o expoente é menor que −4 ou maior ou igual à precisão (6, sem precisão): 100000.0 sai 100000, mas 1e20 sai 1e+20.
  • %f serve para float e double: ao passar por printf, todo float é convertido em double. Por isso, no printf, %lf é igual a %f. No scanf é diferente (veja por quê).
  • %p espera um void *: o jeito certo é printf("%p\n", (void *)&idade).
  • %n é perigoso: um texto vindo do usuário usado como formato pode escrever na memória com ele. É por isso que nunca se escreve printf(texto) (veja Erros comuns).
%b não funciona no editor do guia

O %b é novo (C23). A glibc do Linux já o conhece, mas a biblioteca C do editor (wasi-libc), não: ali, a linha printf("[%b] [%#b] [%B]\n", …) não mostra nada (o printf desiste da linha inteira) e o Clang não avisa. Para mostrar binário no editor, use o laço da aula Operadores de Bits.

Modificadores de tamanho

O modificador vem logo antes da letra e diz o tamanho do valor. Sem ele, %d espera um int. Com l, um long; com ll, um long long; e assim por diante.

O modificador também vale para o %n: %hhn guarda num signed char, %ln num long, e assim por diante.

%Lf (long double) no editor

No editor, um printf("%Lf", …) encerra o programa com esta mensagem (é o padrão da biblioteca C do WebAssembly, para deixar o programa menor):

Support for formatting long double values is currently disabled.
To enable it, add -lc-printscan-long-double to the link command.
Abortado (imagem do núcleo gravada)

Para usar long double no editor, acrescente a opção que a mensagem pede: data-flags="-std=c23 -Wall -Wextra -lc-printscan-long-double". No gcc, %Lf funciona sem nada.

Tipos de tamanho fixo: inttypes.h

Para int64_t, uint8_t etc. (aula stdint.h), o formato certo muda de sistema para sistema (int64_t é long no Linux de 64 bits e long long no editor). A solução portátil são as macros do <inttypes.h>, que viram o texto certo e se "colam" ao resto do formato:

#include <inttypes.h>
int64_t populacao = 123456789012;
printf("População: %" PRId64 "\n", populacao);   // vira "%ld" no gcc e "%lld" no editor

A saída do editor é idêntica, caractere por caractere.

FlagO que fazExemplo → saída

+Mostra o sinal sempre, também o + dos positivos.[%+d] com 42 → [+42]

O *: largura e precisão em variáveis

Um * no lugar do número diz "pegue a largura (ou a precisão) do próximo argumento, que é um int". Os argumentos vêm na ordem em que aparecem: largura, precisão, valor.

FormatoArgumentosSaídaEquivale a
[%*d]6, 7[ 7]%6d
[%-*d]6, 7[7 ]%-6d
[%*d]-6, 7[7 ]largura negativa = flag -
[%.*f]2, 3.14159[3.14]%.2f
[%*.*f]6, 2, 3.14159[ 3.14]%6.2f
%.*s3, "Banana"Ban%.3s (útil para imprimir só um pedaço de uma string)

Atenção: o argumento do * tem de ser int. Um sizeof ou strlen (que são size_t) precisa de conversão: printf("%.*s", (int)strlen(t), t).

O scanf usa quase as mesmas letras, mas ao contrário: em vez de receber valores, recebe endereços de variáveis (por isso o &) e as preenche com o que o usuário digitou. Aula: Entrada com scanf.

Todos esses casos num programa só:

#include <stdio.h>

int main(void) {
    int idade = 0;
    double altura = 0.0;
    char nome[20] = "";
    char cidade[40] = "";
    char letra = '?';
    int lidos = scanf("%d %lf", &idade, &altura);
    printf("lidos=%d idade=%d altura=%.2f\n", lidos, idade, altura);
    lidos = scanf(" %c", &letra);
    printf("lidos=%d letra=%c\n", lidos, letra);
    lidos = scanf("%19s", nome);
    printf("lidos=%d nome=%s\n", lidos, nome);
    lidos = scanf(" %39[^\n]", cidade);
    printf("lidos=%d cidade=%s\n", lidos, cidade);
    int d, m, a;
    lidos = scanf("%d/%d/%d", &d, &m, &a);
    printf("lidos=%d data=%02d/%02d/%d\n", lidos, d, m, a);
    int h = 0, n = 0;
    lidos = scanf("%i %*d %x%n", &h, &d, &n);
    printf("lidos=%d h=%d d=%d n=%d\n", lidos, h, d, n);
    lidos = scanf("%d", &idade);
    printf("lidos=%d\n", lidos);
    lidos = scanf("%d", &idade);
    printf("lidos=%d\n", lidos);
    return 0;
}

Erros que o compilador não pega

O %c "pulou" a pergunta 
#include <stdio.h>

int main(void) {
    int qtd = 0;
    char tam = '?';
    char nome[20] = "";
    printf("Quantidade: ");
    scanf("%d", &qtd);
    printf("Tamanho (P/M/G): ");
    scanf("%c", &tam);
    printf("\nqtd=%d tam=%d\n", qtd, tam);
    printf("Nome completo: ");
    scanf("%19s", nome);
    printf("nome=[%s]\n", nome);
    return 0;
}

$ ./enter
Quantidade: 3                                 « a Ana digita 3 e Enter
Tamanho (P/M/G):
qtd=3 tam=10                                  « nem esperou: o %c leu o Enter (código 10)
Nome completo: M                              « a Ana digita M, achando que é o tamanho
nome=[M]

O que significa: o %d leu o 3 e deixou o Enter na entrada. O %c lê qualquer caractere, inclusive esse Enter.

Como consertar: um espaço antes: scanf(" %c", &tam). O espaço pula os Enters e espaços que sobraram.

O %s só leu o primeiro nome

Com a entrada Ana Souza, scanf("%19s", nome) guarda só Ana; o Souza fica para a próxima leitura.

Como consertar: para uma linha inteira, scanf(" %19[^\n]", nome) ou, melhor, fgets(nome, sizeof nome, stdin) (aula fgets).

%s sem largura: estouro do array

scanf("%s", nome) num char nome[20] aceita uma palavra de 100 letras e escreve além do fim do array, sem nenhum aviso do compilador. No gcc, o programa costuma morrer no fim com *** stack smashing detected ***: terminated (veja Erros Comuns).

Como consertar: sempre %19s (o tamanho do array menos 1, para o '\0'). Aula: Segurança.

O laço com scanf não para nunca

Se o usuário digita abc num %d, o scanf devolve 0 e deixa o abc na entrada. A próxima volta do laço tenta ler o mesmo abc… para sempre.

Como consertar: confira o retorno (if (scanf("%d", &n) != 1)) e descarte a linha ruim (while ((c = getchar()) != '\n' && c != EOF) {}). Aula: Validar a Entrada.

Vírgula ou ponto?

O scanf("%lf") espera ponto: 1.65. Com 1,65, ele lê só o 1 e para na vírgula. O mesmo vale para a saída: %.2f mostra 1.65. Só se o programa chamar setlocale(LC_ALL, "") num sistema em português é que o gcc passa a usar vírgula (3,14); no editor, o setlocale não muda nada.

Experimente

Um laboratório de formatos: troque os formatos e os valores e veja o resultado. Os colchetes mostram onde cada lacuna começa e termina, assim dá para ver os espaços.

Experimente: mude as larguras, as precisões e as flags (-, +, 0, #) e clique em Rodar. Tente prever a saída antes.

int main(void) {

#include <stdio.h>

int main(void) {

        return 1;
    }
    printf("Altura: %.2f m\n", altura);
    return 0;
}

Resumo

  • Formato: %[flags][largura][.precisão][tamanho]letra, nesta ordem. Exemplo: %-10.2lf.
  • Letras: d i u o x X (inteiros), f e g a (ponto flutuante), c, s, p, %%. %b (binário, C23) só funciona no gcc.
  • Tamanhos: hh (char), h (short), l (long), ll (long long), z (size_t), t (ptrdiff_t), j (intmax_t), L (long double). Para int64_t, PRId64.
  • Flags: - esquerda, + sinal, espaço, 0 zeros, # forma alternativa. * tira largura ou precisão de um argumento int.
  • No scanf: endereços (&), %lf para double, " %c" para pular o Enter, %19s com largura, %[^\n] para a linha; confira o retorno (campos lidos, 0 ou EOF).
  • Compile com -Wall: ele pega formato errado, & esquecido e printf(texto).
