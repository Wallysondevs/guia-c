Projeto Boletim de Notas

A Ana dá aula de reforço para uma turma pequena e quer um programa que faça o boletim: ela digita o nome e a nota de cada aluno, e o programa mostra a média da turma, quem tirou a maior e a menor nota, quantos passaram e uma tabela bem alinhada. É o projeto para treinar arrays (muitos valores numa variável só) e structs (vários dados juntos de uma pessoa).

Você vai praticar
  • Guardar várias notas num array e percorrê-lo com for.
  • Somar e tirar a média (e o cuidado com o índice que passa do fim).
  • Juntar nome e nota numa struct e fazer um array de structs.
  • Ler texto com %29s sem estourar o array (Strings).
  • Achar o maior, o menor e contar quem passou, num laço só.
  • Alinhar uma tabela com %-10s e %5.1f (Formatos do printf) e o problema dos acentos.

O boletim pronto, na máquina da Ana, com cinco alunos:

  4. A tabela alinhada (%-10s %5.1f, uma função e a quantidade de alunos).

Antes de começar

Você precisa ter visto Arrays, for e scanf; para a versão 2, Structs. O arquivo vai se chamar boletim.c:

$ mkdir -p c/notas
$ cd c/notas

Versão 1 · As notas num array e a média

Cinco alunos, cinco notas. Daria para criar nota1, nota2… nota5, mas e se a turma tiver 30? Um array guarda todas numa variável só: notas[0] é a primeira, notas[4] a quinta. E um for passa por todas, sem repetir código.

#include <stdio.h>

#define QTD 5

int main(void) {
    double notas[QTD] = {0};
    double soma = 0.0;

    printf("=== Boletim da Turma ===\n");
    for (int i = 0; i < QTD; i++) {
        printf("Nota do aluno %d: ", i + 1);
        if (scanf("%lf", &notas[i]) != 1) {
            printf("\nNota inválida.\n");
            return 1;
        }
        soma += notas[i];
    }

    printf("Notas: ");
    for (int i = 0; i < QTD; i++) {
        printf("%.1f ", notas[i]);
    }
    printf("\nMédia da turma: %.2f\n", soma / QTD);
    return 0;
}

Versão 2 · Nome e nota juntos: um array de structs

Notas sem nome não servem para um boletim. Poderíamos ter dois arrays, um de nomes e um de notas, e cuidar para a posição 2 de um combinar com a posição 2 do outro. Mais simples: uma struct, uma "ficha" com os dados de um aluno, e um array de fichas.

#include <stdio.h>

#define QTD 5

struct Aluno {
    char nome[30];
    double nota;
};

int main(void) {
    struct Aluno turma[QTD];
    double soma = 0.0;

    printf("=== Boletim da Turma ===\n");
    for (int i = 0; i < QTD; i++) {
        printf("Aluno %d (nome e nota): ", i + 1);
        if (scanf("%29s %lf", turma[i].nome, &turma[i].nota) != 2) {
            printf("\nEntrada inválida.\n");
            return 1;
        }
        soma += turma[i].nota;
    }

    printf("\n");
    for (int i = 0; i < QTD; i++) {
        printf("%s: %.1f\n", turma[i].nome, turma[i].nota);
    }
    printf("Média da turma: %.2f\n", soma / QTD);
    return 0;
}
struct Aluno { char nome[30]; double nota; };
Cria um tipo novo: cada struct Aluno tem um nome (texto de até 29 letras mais o '\0', veja Strings) e uma nota. O ; depois da } é obrigatório.
struct Aluno turma[QTD];
Um array de 5 fichas. turma[0] é a ficha do primeiro aluno.
turma[i].nome e turma[i].nota
O ponto entra na ficha: "o nome da ficha i".
scanf("%29s %lf", turma[i].nome, &turma[i].nota)
Lê uma palavra e um número. %29s lê no máximo 29 caracteres: sobra lugar para o '\0' e o nome nunca passa do fim do array. O nome não leva &: um array já é o endereço do seu começo (veja Ponteiros e Arrays).

Entrada inválida.

O último teste mostra um limite do %s: ele lê uma palavra, até o primeiro espaço. Em Ana Paula 8, o nome ficou Ana, e o %lf tentou ler Paula como número e falhou. Para nomes com espaço, seria preciso ler a linha com fgets e separar nome e nota (é um dos desafios). Por enquanto, um nome por aluno.

Nunca use %s sem o tamanho

Com scanf("%s", nome), alguém que digite um nome de 100 letras escreve 100 bytes num array de 30, e o programa estraga a memória ao lado (como no cenário da versão 1). É o famoso buffer overflow (veja Segurança). Sempre um a menos que o tamanho do array: char nome[30] → %29s.

Missão (versão 2): o programa lê os cinco alunos, mas só mostra a média. Antes dela, escreva um for que mostra cada aluno no formato Bruno: 7.5, usando turma[i].nome e turma[i].nota com %.1f.

#include <stdio.h>

#define QTD 5

struct Aluno {
    char nome[30];
    double nota;
};

int main(void) {
    struct Aluno turma[QTD];
    double soma = 0.0;

    printf("=== Boletim da Turma ===\n");
    for (int i = 0; i < QTD; i++) {
        printf("Aluno %d (nome e nota): ", i + 1);
        if (scanf("%29s %lf", turma[i].nome, &turma[i].nota) != 2) {
            printf("\nEntrada inválida.\n");
            return 1;
        }
        soma += turma[i].nota;
    }

    printf("\n");
    // mostre cada aluno no formato "Bruno: 7.5"
    printf("Média da turma: %.2f\n", soma / QTD);
    return 0;
}

Versão 3 · Maior, menor e aprovados

Agora as estatísticas. Para achar a maior nota, o jeito clássico é: "a maior até agora é a do primeiro aluno; para cada um dos outros, se a nota dele for maior, ele passa a ser o maior". Guardamos a posição (não a nota), porque assim sabemos também o nome. A menor nota é igual, com <. E os aprovados são um contador que sobe quando a nota é pelo menos 6.

#include <stdio.h>

#define QTD 5
#define MEDIA_APROVACAO 6.0

struct Aluno {
    char nome[30];
    double nota;
};

int main(void) {
    struct Aluno turma[QTD];
    double soma = 0.0;

    printf("=== Boletim da Turma ===\n");
    for (int i = 0; i < QTD; i++) {
        printf("Aluno %d (nome e nota): ", i + 1);
        if (scanf("%29s %lf", turma[i].nome, &turma[i].nota) != 2) {
            printf("\nEntrada inválida.\n");
            return 1;
        }
        soma += turma[i].nota;
    }

    int maior = 0;  // posição do aluno com a maior nota
    int menor = 0;  // posição do aluno com a menor nota
    int aprovados = 0;
    for (int i = 0; i < QTD; i++) {
        if (turma[i].nota > turma[maior].nota) {
            maior = i;
        }
        if (turma[i].nota < turma[menor].nota) {
            menor = i;
        }
        if (turma[i].nota >= MEDIA_APROVACAO) {
            aprovados++;
        }
    }

    printf("\nMédia da turma: %.2f\n", soma / QTD);
    printf("Maior nota: %.1f (%s)\n", turma[maior].nota, turma[maior].nome);
    printf("Menor nota: %.1f (%s)\n", turma[menor].nota, turma[menor].nome);
    printf("Aprovados: %d de %d\n", aprovados, QTD);
    return 0;
}
#define MEDIA_APROVACAO 6.0
A nota mínima para passar, com nome. Ninguém precisa adivinhar o que é aquele 6.0 no meio do código.
int maior = 0;
A posição do aluno com a maior nota. Começa no primeiro (posição 0).
if (turma[i].nota > turma[maior].nota) maior = i;
Compara com a maior até agora; se ganhou, troca a posição.
if (turma[i].nota >= MEDIA_APROVACAO) aprovados++;
Conta quem passou. >=: quem tirou exatamente 6 também passa.
turma[maior].nome

E se houver empate?

Com >, o primeiro aluno com a maior nota fica com o título; com >=, ficaria o último. Nenhum dos dois está errado, mas é bom saber qual você escolheu.

Versão 4 · A tabela alinhada

A versão final tem três novidades:

  • A quantidade de alunos é perguntada no começo (de 1 a 30). O array tem 30 posições, mas o programa só usa as qtd primeiras.
  • Uma função situacao devolve o texto "Aprovado", "Recuperação" (de 4 a 5.9) ou "Reprovado".
  • Uma tabela, com as colunas alinhadas pela largura dos formatos do printf.
#include <stdio.h>

#define MAX_ALUNOS 30
#define MEDIA_APROVACAO 6.0

struct Aluno {
    char nome[30];
    double nota;
};

const char *situacao(double nota) {
    if (nota >= MEDIA_APROVACAO) {
        return "Aprovado";
    } else if (nota >= 4.0) {
        return "Recuperação";
    }
    return "Reprovado";
}

int main(void) {
    struct Aluno turma[MAX_ALUNOS];
    int qtd = 0;

    printf("=== Boletim da Turma ===\n");
    printf("Quantos alunos (1 a %d)? ", MAX_ALUNOS);
    if (scanf("%d", &qtd) != 1 || qtd < 1 || qtd > MAX_ALUNOS) {
        printf("\nQuantidade inválida.\n");
        return 1;
    }

    double soma = 0.0;
    for (int i = 0; i < qtd; i++) {
        printf("Aluno %d (nome e nota): ", i + 1);
        if (scanf("%29s %lf", turma[i].nome, &turma[i].nota) != 2) {
            printf("\nEntrada inválida.\n");
            return 1;
        }
        soma += turma[i].nota;
    }

    int maior = 0;
    int menor = 0;
    int aprovados = 0;
    printf("\n%-10s %5s  %s\n", "Aluno", "Nota", "Situação");
    printf("---------- -----  -----------\n");
    for (int i = 0; i < qtd; i++) {
        printf("%-10s %5.1f  %s\n", turma[i].nome, turma[i].nota, situacao(turma[i].nota));
        if (turma[i].nota > turma[maior].nota) {
            maior = i;
        }
        if (turma[i].nota < turma[menor].nota) {
            menor = i;
        }
        if (turma[i].nota >= MEDIA_APROVACAO) {
            aprovados++;
        }
    }
    printf("---------- -----  -----------\n");
    printf("%-11s %5.1f\n", "Média", soma / qtd);  // 11: o "é" ocupa 2 bytes
    printf("\nMaior nota: %.1f (%s)\n", turma[maior].nota, turma[maior].nome);
    printf("Menor nota: %.1f (%s)\n", turma[menor].nota, turma[menor].nome);
    printf("Aprovados: %d de %d\n", aprovados, qtd);
    return 0;
}

A função devolve um texto fixo: um ponteiro para o primeiro caractere de "Aprovado", por exemplo (veja Ponteiros e Strings). O const avisa que ninguém deve mudar esse texto.

O que aconteceu: o printf conta bytes, não letras. No UTF-8, letras acentuadas como é, á e ú ocupam 2 bytes. "Fábio" tem 5 letras, mas 6 bytes; o %-10s acha que já usou 6 posições e completa com só 4 espaços. Na tela, a coluna fica um passo para a esquerda.

Como consertar: para um texto fixo, como "Média", aumente a largura no número de letras acentuadas: %-11s. Para nomes digitados, conte as letras de verdade e complete com espaços você mesmo (é o desafio 3). A aula Acentos e UTF-8 explica os bytes.

Exercícios

1. Um array declarado como double notas[5] tem quais posições válidas?

2. Por que o scanf usa %29s para um char nome[30]?

3. O que printf("[%-6s]", "Ana") mostra?

4. Por que o programa guarda a posição da maior nota em vez da nota?

5. Complete o formato que mostra uma nota com uma casa decimal numa coluna de 5 posições:

printf("", 7.5);

6. Complete o acesso à nota do terceiro aluno do array turma:

turma[].nota

Resumo

  • Um array guarda muitos valores do mesmo tipo; as posições vão de 0 a tamanho - 1, e o laço é i < tamanho.
  • Passar do fim do array não dá erro de compilação: estraga a memória ao lado. O -fsanitize=address mostra a linha.
  • Uma struct junta os dados de uma coisa (nome e nota); um array de structs guarda a turma.
  • %29s lê uma palavra sem passar de 29 letras; %s para no primeiro espaço.
  • Maior e menor: comece pelo primeiro e troque quando achar um melhor; guarde a posição.
  • %-10s alinha texto à esquerda, %5.1f alinha números; o printf conta bytes, então acentos desalinham.
