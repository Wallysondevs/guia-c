Tabela de precedência e associatividade

A precedência diz qual operador "pega" seus valores primeiro, como na matemática: em 2 + 3 * 4, o * vem antes, e o resultado é 14. A associatividade decide entre operadores da mesma linha: da esquerda para a direita (10 - 3 - 2 = (10 - 3) - 2 = 5) ou da direita para a esquerda (a = b = 0 = a = (b = 0)).

Na tabela, a linha 1 é a mais forte (calculada primeiro) e a 15, a mais fraca. Na dúvida, use parênteses: eles sempre ganham, e deixam o código mais claro.

Para decorar

De cima para baixo: unários (um valor só) → contas (* / %, depois + -) → deslocamento → comparações → bits (& ^ |) → lógicos (&&, depois ||) → ternário → atribuição → vírgula. Os operadores de bits ficam abaixo das comparações (é uma herança antiga do C): por isso, com &, | e ^, sempre use parênteses.

Precedência não é ordem de execução. Ela diz como a expressão é agrupada, não qual parte roda primeiro. Em f() + g() * h(), a multiplicação é agrupada antes, mas o C não diz qual das três funções é chamada primeiro. Só &&, ||, ?: e a vírgula garantem a ordem (da esquerda para a direita).

Use unsigned com operadores de bits. Com int, 1 << 31 é comportamento indefinido (deu -2147483648 nos dois, sem aviso); com 1u << 31, é 2147483648. Deslocar por um número de casas maior ou igual ao tamanho do tipo também é indefinido: 1 << n com n = 32 deu 1 nos dois, e não 0.

Vírgula como operador e vírgula que separa argumentos são coisas diferentes: em printf("%d %d", a, b), as vírgulas só separam.

    printf("com double: %.2f %.2f\n", 17 / 5.0, (double)a / b);
    printf("unários: %d %d\n", -a, +a);
    int x = 10;
    x += 5;  printf("x += 5  -> %d\n", x);
    x -= 3;  printf("x -= 3  -> %d\n", x);

    x /= 5;  printf("x /= 5  -> %d\n", x);
    x %= 3;  printf("x %%= 3  -> %d\n", x);
    x <<= 4; printf("x <<= 4 -> %d\n", x);
    x >>= 1; printf("x >>= 1 -> %d\n", x);
    x &= 6;  printf("x &= 6  -> %d\n", x);
    x |= 1;  printf("x |= 1  -> %d\n", x);
    x ^= 3;  printf("x ^= 3  -> %d\n", x);
    int i = 5;
    int pos = i++;
    printf("i++: valor %d, i agora %d\n", pos, i);

    printf("++i: valor %d, i agora %d\n", pre, i);

Armadilhas

Este programa compila (no gcc) e roda, mas quase nenhuma linha faz o que parece. O -Wall avisa de todas:

#include <stdio.h>

int main(void) {
    int flags = 6;
    if (flags & 4 == 4) printf("bit 2 ligado\n");
    int x = 1 << 2 + 1;
    printf("1 << 2 + 1 = %d\n", x);
    int idade = 15;
    if (idade = 18) printf("maior de idade (idade = %d)\n", idade);
    int a = 2, b = 3;
    if (a < b < 1) printf("a < b < 1 é verdade?!\n");
    int i = 1;
    i = i++ + 1;
    printf("i = %d\n", i);
    if (!a == 5) printf("nunca\n");
    printf("%d\n", a && b || 0 && 1);
    return 0;
}

*p++ não soma 1 no valor

Com int *p = v;, a linha *p++; não aumenta v[0]: o ++ (nível 1) pega o p antes do * (nível 2), então ela anda o ponteiro para o próximo item (depois dela, v[0] continua 10 e *p vale 20). O compilador desconfia: value computed is not used [-Wunused-value] no gcc, expression result unused [-Wunused-value] no Clang. Como consertar: para aumentar o valor apontado, (*p)++. Aula: Ponteiros e Arrays.

Dividir por zero

7 / zero com int zero = 0; não dá aviso, e o programa morre nos dois: no gcc, Exceção de ponto flutuante (imagem do núcleo gravada); no editor, a mesma mensagem e [código de saída: 136]. (O nome é antigo: vale também para divisão de inteiros.) Como consertar: teste antes, if (divisor != 0). Com double, dividir por zero não derruba: 7 / 0.0 mostra inf (infinito) e 0 / 0.0 mostra -nan ("não é um número"), nos dois. Aula: Aritméticos.

Experimente

Experimente: antes de clicar em Rodar, escreva num papel o que cada linha vai mostrar, usando a tabela de precedência. Depois, ponha parênteses e veja o que muda.

#include <stdio.h>

int main(void) {
    int a = 6, b = 3, c = 2;
    printf("%d\n", a + b * c);
    printf("%d\n", a / b * c);
    printf("%d\n", a - b - c);
    printf("%d\n", a % 4 + b);
    printf("%d\n", -a / 4);
    printf("%d\n", a > b && b > c);
    printf("%d\n", a == 6 || b++ == 99);
    printf("b depois: %d\n", b);
    printf("%d\n", a > b ? a : b);
    return 0;
}

Missão: as permissões da Ana estão em flags = 6 (0b110): o bit 2 (que vale 4) está ligado, mas o programa não o vê, e o compilador avisa. Ponha os parênteses no lugar certo para sair bit 2 ligado, sem nenhum aviso.

#include <stdio.h>

int main(void) {
    int flags = 6;
    if (flags & 4 == 4) {
        printf("bit 2 ligado\n");
    }
    return 0;
}

#include <stdio.h>

int main(void) {
    int flags = 6;
    if ((flags & 4) == 4) {
        printf("bit 2 ligado\n");
    }
    return 0;
}

Resumo

  • Precedência, do mais forte ao mais fraco: pós-fixos (a++ f() v[i] . ->) → unários (! ~ - * & sizeof cast) → * / % → + - → << >> → < <= > >= → == != → & → ^ → | → && → || → ?: → atribuições → ,.
  • Da direita para a esquerda: os unários, o ?: e as atribuições. O resto, da esquerda para a direita.
  • Divisão de inteiros corta a parte decimal; % tem o sinal do primeiro número.
  • && e || param assim que sabem a resposta (curto-circuito).
  • Com &, |, ^ e <<, use parênteses. = guarda, == compara. Não mude a mesma variável duas vezes numa expressão.
