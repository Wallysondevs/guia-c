C Ordenação (qsort)

Ordenar é pôr em ordem: as notas da turma da maior para a menor, os nomes em ordem alfabética, os produtos do mais barato ao mais caro. É uma das tarefas mais comuns da programação, e também a base para procurar depressa. Nesta aula você vai ordenar à mão uma vez, para entender o que acontece por dentro, e depois usar o qsort da biblioteca padrão para ordenar qualquer coisa: números, textos e structs, com o critério que você quiser.

Você vai aprender
  • Como funciona um algoritmo de ordenação simples, a ordenação por inserção.
  • Os quatro argumentos do qsort e a regra da função de comparação (negativo, zero, positivo).
  • Como comparar sem estourar o int, e como inverter a ordem.
  • Como ordenar double, textos (char * e char[][N]) e structs.
  • Como desempatar por um segundo critério, e por que o qsort não é estável.
  • Os erros clássicos: assinatura errada, strcmp no ponteiro errado, x - y e tamanho errado.

Esta aula continua a aula Ponteiros para Funções, que apresentou o qsort, e usa ponteiro void* e structs e ponteiros. Todos os programas foram compilados com o gcc 15.2 na máquina fictícia da Ana (usuária ana, computador notebook), na pasta ~/c, com o comando padrão do guia: gcc -std=c23 -Wall -Wextra arquivo.c -o programa.

A ideia: as cartas na mão

A Ana está jogando baralho e recebe as cartas uma de cada vez. A cada carta nova, ela a encaixa no lugar certo entre as que já estão na mão: passa pelas maiores, empurrando-as um pouco para o lado, até achar uma menor. A mão está sempre em ordem, e no fim todas as cartas estão ordenadas.

Qualquer jeito de ordenar, por mais esperto que seja, se resume a duas operações: comparar dois itens ("qual vem antes?") e mudar itens de lugar. O que muda de um algoritmo para outro é quais pares ele compara e quantas vezes.

1. Ordenar à mão: a inserção

O jeito da Ana tem nome: ordenação por inserção (insertion sort). Em C, a "mão" é o começo do array, que já está ordenado, e a "carta nova" é o próximo item:

#include <stdio.h>

void mostrar(const int *v, int n) {
    for (int i = 0; i < n; i++) {
        printf(" %d", v[i]);
    }
    printf("\n");
}

void ordenar_insercao(int *v, int n) {
    for (int i = 1; i < n; i++) {
        int carta = v[i];
        int j = i - 1;
        while (j >= 0 && v[j] > carta) {
            v[j + 1] = v[j];
            j--;
        }
        v[j + 1] = carta;
        printf("depois de encaixar o %2d:", carta);
        mostrar(v, n);
    }
}

int main(void) {
    int cartas[] = {7, 3, 10, 5, 9, 1};
    int n = sizeof cartas / sizeof cartas[0];
    printf("no começo:              ");
    mostrar(cartas, n);
    ordenar_insercao(cartas, n);
    return 0;
}

depois de encaixar o  3: 3 7 10 5 9 1

depois de encaixar o  9: 3 5 7 9 10 1
depois de encaixar o  1: 1 3 5 7 9 10
for (int i = 1; i < n; i++)
Começa no segundo item: um array de um item só (o v[0]) já está ordenado. A cada volta, v[0] a v[i - 1] é a "mão" ordenada.
int carta = v[i];
Guarda a carta nova, porque a posição dela vai ser ocupada por quem andar para a direita.
while (j >= 0 && v[j] > carta)
Enquanto houver carta na mão e ela for maior que a nova, continua procurando para a esquerda. O j >= 0 vem antes: se j for -1, o && para ali e v[-1] nunca é lido (veja Operadores Lógicos).
v[j + 1] = v[j]; j--;
Empurra a carta maior uma casa para a direita e olha a próxima à esquerda.
v[j + 1] = carta;
Achou o lugar: logo depois da primeira carta que não é maior. Encaixa ali.

Repare no "encaixar o 1": ele é o menor de todos, então todas as outras cinco cartas andaram uma casa. A inserção é ótima para arrays pequenos ou quase ordenados, mas, num array grande e bagunçado, cada carta nova pode empurrar quase todas as anteriores. Com o dobro de itens, o trabalho fica quatro vezes maior. A seção 6 mede isso.

2. O qsort: a ordenação pronta

A biblioteca padrão já tem uma ordenação rápida e testada: o qsort, de <stdlib.h>. O nome vem de quicksort ("ordenação rápida"), o algoritmo das primeiras versões; hoje cada biblioteca usa o algoritmo que quiser, e o padrão do C só promete que o array termina ordenado. O que torna o qsort especial é que ele ordena arrays de qualquer tipo:

#include <stdio.h>
#include <stdlib.h>

int crescente(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

int main(void) {
    int notas[] = {7, 3, 10, 5, 9, 1, 8};
    size_t n = sizeof notas / sizeof notas[0];

    qsort(notas, n, sizeof notas[0], crescente);

    for (size_t i = 0; i < n; i++) {
        printf("%d ", notas[i]);
    }
    printf("\n");
    return 0;
}

$ gcc -std=c23 -Wall -Wextra qsort_int.c -o qsort_int
$ ./qsort_int
1 3 5 7 8 9 10

O protótipo, como está no stdlib.h, é: void qsort(void *base, size_t n, size_t tamanho, int (*comparar)(const void *, const void *));

ArgumentoNa chamadaO que é
void *basenotasOnde o array começa. Como é void *, aceita o endereço de qualquer array (aula Ponteiro void*).
size_t nnQuantos itens ordenar (não quantos bytes). Aqui, 7, calculado com sizeof notas / sizeof notas[0].
size_t tamanhosizeof notas[0]Quantos bytes tem cada item. O qsort não sabe o tipo, então precisa disso para pular de um item para o outro e para trocá-los de lugar.

Escreva sizeof notas[0], não sizeof(int)

Os dois dão 4 aqui. Mas, se um dia o array virar double, o sizeof notas[0] acompanha sozinho, e o sizeof(int) fica errado sem nenhum aviso (é um dos erros da seção Quando dá errado).

3. A função de comparação

O qsort entrega à sua função os endereços de dois itens do array, a e b, como const void *. A função devolve um int que segue uma regra fixa:

DevolveQuer dizer
Um número negativo (qualquer um: -1, -50…)a vem antes de b
ZeroTanto faz: para este critério, os dois são iguais
Um número positivoa vem depois de b
int crescente(const void *a, const void *b)
A forma é obrigatória: dois const void * e retorno int. O const promete que a comparação só lê, sem mudar os itens.
int x = *(const int *)a;
Converte o void * para o tipo verdadeiro dos itens (const int *) e lê o valor com o *. Sem a conversão, o C não saberia quantos bytes ler.
return (x > y) - (x < y);
Uma comparação em C vale 1 (verdadeiro) ou 0 (falso). Se x > y: 1 - 0 = 1. Se x < y: 0 - 1 = -1. Se iguais: 0 - 0 = 0. É o mesmo que os dois if da aula Ponteiros para Funções, numa linha.

Três jeitos de escrever, e um que parece certo

Corpo da comparaçãoFunciona?
if (x < y) return -1; if (x > y) return 1; return 0;Sim. O mais fácil de ler.
return (x > y) - (x < y);Sim. Curto, e muito usado em código C.
return x < y ? -1 : x > y;Sim, com o ternário. Menos comum.
return x - y;Só com números pequenos. Com números grandes, a subtração estoura o int e o sinal sai errado (veja Quando dá errado).

Para inverter a ordem (do maior para o menor), troque x e y de lugar: return (y > x) - (y < x);. O qsort é o mesmo; só o critério mudou.

4. Ordenar textos

Textos se comparam com strcmp (aula Funções de String), que já segue a regra do qsort: negativo se o primeiro vem antes no alfabeto, zero se iguais, positivo se vem depois. A pegadinha é o que o qsort entrega para a sua função, e isso depende de como os textos estão guardados.

Um array de ponteiros: const char *turma[]

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int por_nome(const void *a, const void *b) {
    const char *x = *(const char *const *)a;
    const char *y = *(const char *const *)b;
    return strcmp(x, y);
}

int main(void) {
    const char *turma[] = {"Rui", "Ana", "Lia", "Bruno", "Davi", "Ana Clara"};
    size_t n = sizeof turma / sizeof turma[0];

    qsort(turma, n, sizeof turma[0], por_nome);

    for (size_t i = 0; i < n; i++) {
        printf("%s\n", turma[i]);
    }
    return 0;
}

Cada item do array é um ponteiro para um texto. É isso que o qsort ordena: os ponteiros mudam de lugar, os textos ficam onde estão.
*(const char *const *)a
O qsort entrega o endereço de um item. Como cada item é um const char *, a é, na verdade, um ponteiro para ponteiro (const char *const *; aula Ponteiro para Ponteiro). O * da frente lê o item: o ponteiro para o texto.
strcmp(x, y)
Agora sim, compara os dois textos. "Ana" vem antes de "Ana Clara" porque é um pedaço dela: o texto mais curto termina primeiro.

Um array de textos: char turma[][12]

Se os textos estiverem guardados dentro do array (um array de duas dimensões), cada item já é o texto, e o qsort entrega o endereço do primeiro caractere dele:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int por_nome(const void *a, const void *b) {
    return strcmp((const char *)a, (const char *)b);
}

int main(void) {
    char turma[][12] = {"Rui", "Ana", "Lia", "Bruno", "Davi", "Ana Clara"};
    size_t n = sizeof turma / sizeof turma[0];

    qsort(turma, n, sizeof turma[0], por_nome);

    for (size_t i = 0; i < n; i++) {
        printf("%s\n", turma[i]);
    }
    printf("Cada item tem %zu bytes\n", sizeof turma[0]);
    return 0;
}

Aqui a já aponta para o texto, então basta strcmp(a, b), sem o * extra. E o qsort troca de lugar os 12 bytes de cada nome, não um ponteiro. O resultado é o mesmo; a função de comparação é diferente:

Maiúsculas, minúsculas e acentos

O strcmp compara os códigos dos caracteres. Todas as maiúsculas vêm antes de todas as minúsculas ("Zeca" antes de "ana"), e letras acentuadas (que em UTF-8 têm códigos altos) vão para o fim: "Ícaro" depois de "Zeca". Para uma ordem "de dicionário", é preciso comparar de outro jeito (por exemplo, convertendo para minúsculas com tolower antes; veja ctype.h).

5. Ordenar structs e desempatar

Com structs, a função de comparação escolhe o campo que decide a ordem. O ranking da turma da Ana: maior nota primeiro e, entre notas iguais, ordem alfabética:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char nome[20];
    int nota;
} Aluno;

int ranking(const void *a, const void *b) {
    const Aluno *x = a;
    const Aluno *y = b;
    if (x->nota != y->nota) {
        return (y->nota > x->nota) - (y->nota < x->nota);
    }
    return strcmp(x->nome, y->nome);
}

int main(void) {
    Aluno turma[] = {
        {"Rui", 7}, {"Lia", 9}, {"Bruno", 7}, {"Ana", 10},
        {"Davi", 9}, {"Caio", 5}, {"Bia", 7},
    };
    size_t n = sizeof turma / sizeof turma[0];

    qsort(turma, n, sizeof turma[0], ranking);

    for (size_t i = 0; i < n; i++) {
        printf("%zuº %-6s %2d\n", i + 1, turma[i].nome, turma[i].nota);
    }
    return 0;
}

4º Bia     7

Em C, um void * vira outro ponteiro sozinho, sem cast (aula Ponteiro void*). Daí em diante, x->nota e x->nome.
if (x->nota != y->nota)
O primeiro critério: a nota. Se forem diferentes, ela decide sozinha.
(y->nota > x->nota) - (y->nota < x->nota)
Com y na frente: ordem decrescente (maior nota primeiro).
return strcmp(x->nome, y->nome);
O desempate: só chega aqui com notas iguais. Davi e Lia (9) e Bia, Bruno e Rui (7) saíram em ordem alfabética.
%zuº
O %zu é o formato do size_t (veja Formatos do printf); o º é só texto.

Sem desempate: o qsort não é estável

Uma ordenação é estável quando itens empatados continuam na ordem em que estavam. O padrão do C não promete que o qsort seja estável, e cada biblioteca faz de um jeito. Este programa ordena só pela nota uma turma em que todos estão em ordem alfabética:

#include <stdio.h>
#include <stdlib.h>

typedef struct {
    char nome[8];
    int nota;
} Aluno;

int por_nota(const void *a, const void *b) {
    const Aluno *x = a;
    const Aluno *y = b;
    return (x->nota > y->nota) - (x->nota < y->nota);
}

int main(void) {
    Aluno turma[] = {
        {"Ana", 8}, {"Bia", 6}, {"Caio", 8}, {"Davi", 6}, {"Edu", 8},
        {"Fabi", 6}, {"Gil", 8}, {"Hugo", 6}, {"Iris", 8}, {"Joao", 6},
    };
    size_t n = sizeof turma / sizeof turma[0];
    qsort(turma, n, sizeof turma[0], por_nota);
    for (size_t i = 0; i < n; i++) {
        printf("%s(%d) ", turma[i].nome, turma[i].nota);
    }
    printf("\n");
    return 0;
}

$ ./estavel

#include <stdlib.h>

typedef struct {
    char nome[8];
    int nota;
} Aluno;

int por_nota(const void *a, const void *b) {
    const Aluno *x = a;
    const Aluno *y = b;
    return (x->nota > y->nota) - (x->nota < y->nota);
}

int main(void) {
    Aluno turma[] = {
        {"Ana", 8}, {"Bia", 6}, {"Caio", 8}, {"Davi", 6}, {"Edu", 8},
        {"Fabi", 6}, {"Gil", 8}, {"Hugo", 6}, {"Iris", 8}, {"Joao", 6},
    };
    size_t n = sizeof turma / sizeof turma[0];
    qsort(turma, n, sizeof turma[0], por_nota);
    for (size_t i = 0; i < n; i++) {
        printf("%s(%d) ", turma[i].nome, turma[i].nota);
    }
    printf("\n");
    return 0;
}

Nenhuma das duas está errada: para o critério "nota", empatados são iguais, e o qsort pode pô-los em qualquer ordem. A lição é: se a ordem dos empatados importa, ela precisa estar na função de comparação. Um bom critério de desempate é um campo que não se repete (o nome, uma matrícula). Assim, o resultado é o mesmo em qualquer computador.

Ordenar só um pedaço

Como o qsort recebe um endereço e uma quantidade, dá para ordenar só uma parte do array: passe o endereço do primeiro item do pedaço (aritmética de ponteiros) e quantos itens ele tem.

#include <stdio.h>
#include <stdlib.h>

int crescente(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

int main(void) {
    int v[] = {9, 8, 7, 6, 5, 4, 3};
    qsort(v + 2, 3, sizeof v[0], crescente);
    for (int i = 0; i < 7; i++) {
        printf("%d ", v[i]);
    }
    printf("\n");
    return 0;
}

$ gcc -std=c23 -Wall -Wextra parte.c -o parte
$ ./parte
9 8 5 6 7 4 3

v + 2 é o endereço do v[2]; com 3 itens, só v[2], v[3] e v[4] (o 7, o 6 e o 5) foram ordenados. O resto ficou como estava.

6. Quanto tempo leva

Este programa ordena os mesmos 100 mil números duas vezes, com a inserção da seção 1 e com o qsort, e mede o tempo de cada uma com clock() (aula Data e Hora). Os números vêm de um sorteador próprio, para serem os mesmos a cada execução:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>

int crescente(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

void ordenar_insercao(int *v, int n) {
    for (int i = 1; i < n; i++) {
        int carta = v[i];
        int j = i - 1;
        while (j >= 0 && v[j] > carta) {
            v[j + 1] = v[j];
            j--;
        }
        v[j + 1] = carta;
    }
}

int main(void) {
    const int n = 100000;
    int *a = malloc(n * sizeof *a);
    int *b = malloc(n * sizeof *b);
    if (a == NULL || b == NULL) {
        free(a);
        free(b);
        return 1;
    }
    unsigned int semente = 42;
    for (int i = 0; i < n; i++) {
        semente = semente * 1103515245u + 12345u;
        a[i] = (int)(semente / 65536u % 1000000u);
    }
    memcpy(b, a, n * sizeof *a);

    clock_t t0 = clock();
    ordenar_insercao(a, n);
    clock_t t1 = clock();
    qsort(b, n, sizeof *b, crescente);
    clock_t t2 = clock();

    printf("inserção: %.3f s\n", (double)(t1 - t0) / CLOCKS_PER_SEC);
    printf("qsort:    %.3f s\n", (double)(t2 - t1) / CLOCKS_PER_SEC);
    printf("iguais? %s\n", memcmp(a, b, n * sizeof *a) == 0 ? "sim" : "não");
    free(a);
    free(b);
    return 0;
}

$ gcc -std=c23 -Wall -Wextra tempo.c -o tempo
$ ./tempo
inserção: 7.738 s
qsort:    0.019 s
iguais? sim

O mesmo resultado (iguais? sim, conferido com memcmp), umas 400 vezes mais depressa. Os tempos mudam de um computador para outro, mas a diferença continua enorme. A inserção compara cada número com uma boa parte dos anteriores: com 100 mil números, são bilhões de comparações. Os algoritmos do qsort (quicksort, mergesort e parentes) dividem o array em pedaços e precisam só de uns 2 milhões. (No editor do guia este programa passa do limite de 15 segundos; deixe-o para o terminal.)

Tamanho errado: sizeof(int) num array de double

$ ./tamanho

O que significa: nenhum aviso: para o compilador, sizeof(int) é só um número. Mas cada double tem 8 bytes, e o qsort achou que cada item tinha 4. Ele trocou de lugar metades de double e só mexeu nos primeiros 20 bytes do array (5 itens de 4 bytes). No gcc, o resultado "parece quase certo", o que é o pior caso: passa despercebido. No editor, uma das trocas montou um double com a metade de um e a metade de outro, e apareceu no lugar do 0,75 um número com 186 dígitos.

Como consertar: use sempre sizeof v[0] (o tamanho do item do próprio array) e sizeof v / sizeof v[0] para a quantidade.

    char nome[20];

int comparar(const void *a, const void *b) {
    const Produto *x = a;
    const Produto *y = b;

Resumo

  • Ordenar é comparar e mudar de lugar. A inserção encaixa cada item entre os já ordenados; é simples, mas lenta com muitos itens.
  • qsort(v, n, sizeof v[0], comparar) ordena um array de qualquer tipo: o endereço, quantos itens, o tamanho de cada um e a sua função de comparação.
  • A comparação recebe dois const void *, converte para o tipo certo e devolve negativo (a antes), zero (tanto faz) ou positivo (a depois). Use (x > y) - (x < y); x - y pode estourar. Para inverter, troque x e y.
  • Textos: strcmp. Num const char *v[], a é um ponteiro para ponteiro (*(const char *const *)a); num char v[][N], a já é o texto.
  • Structs: compare o campo que decide e desempate por outro. O qsort não é estável: sem desempate, empatados podem sair em ordens diferentes em cada biblioteca.
